# Support Guidelines

Thank you for using **GitHub Green Squares — Developer Contribution Analytics**!

Here is how you can get help, report issues, or suggest new features for the project.

---

## 🐛 Reporting Bugs

If you find a bug, rendering defect, or calculation discrepancy:

1. Search existing issues to ensure it has not already been reported:  
   [https://github.com/somansinghal/Green_squares/issues](https://github.com/somansinghal/Green_squares/issues)
2. If no existing issue exists, open a new issue using a descriptive title.
3. Provide details:
   - Your browser and version (e.g., Chrome 129 on macOS).
   - Viewport width if it is a responsive layout issue (e.g., 390px iPhone 15).
   - Clear steps to reproduce the problem.
   - Any console output or screenshots.

---

## 💡 Requesting Features

Have an idea for a new metric, visualization chart, or workflow improvement?

1. Check existing feature discussions in GitHub Issues:  
   [https://github.com/somansinghal/Green_squares/issues](https://github.com/somansinghal/Green_squares/issues)
2. Open a new issue with the label `enhancement`.
3. Explain the user problem the feature solves and how it fits into developer productivity.

---

## ❓ Asking Questions

For questions regarding local development, configuring GitHub OAuth, or deploying to Vercel:

- Open a discussion or question in GitHub Issues:  
  [https://github.com/somansinghal/Green_squares/issues](https://github.com/somansinghal/Green_squares/issues)
- Review the setup guides in [README.md](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md).
